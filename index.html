30分で身につける、仕事で使える英会話

中学英語が多少わかるレベルから、会議・報告・依頼・交渉・面接まで。単語・イディオム・表現パターン・ロールプレイを 30 分に凝縮した、講師付き 1on1 レッスン用のテキストです。 Claude Code を講師にして、そのまま実践レッスンができます。

使い方

1. Claude Code を講師にする(おすすめ)

リポジトリを clone して claude を起動し、/lesson 01 と打つだけ。Claude がテキストに沿って 30 分のレッスンを進行し、相手役・発音/文法の指摘・最後のフィードバックまで行います。

2. 人間の講師と使う

各レッスンには時間配分・講師用メモ・モデル対話・ドリルの答えがそろっています。講師はこのページを開きながら進行できます。

3. ひとりで予習・復習する

単語表と表現パターンを音読し、ロールプレイの Ken のセリフを声に出して練習。レッスンページのタイマーで 30 分の流れを体感できます。

Claude Code でレッスンを始める手順

  1. リポジトリを clone する
    git clone https://github.com/ke-iwata/english-lerning.git && cd english-lerning
  2. Claude Code を起動する
    claude
  3. レッスン番号を指定して開始する(音声入力を使うと会話練習として効果的です)
    /lesson 01
  4. 終了後、Claude が progress/log.md に記録と弱点メモを残します。復習は /review で。

レッスン中は、英語で話すのが基本ですが、分からないときは日本語で「ヒントちょうだい」「もう一回」「日本語で説明して」と言えば、講師(Claude)が日本語で助けてくれます。
