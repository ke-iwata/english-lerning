使い方

1. Claude Code を講師にする(おすすめ)

リポジトリを clone して claude を起動し、/lesson 01 と打つだけ。Claude がテキストに沿って 30 分のレッスンを進行し、相手役・文法の指摘・最後のフィードバックまで行います。音声入力 + 読み上げで、声だけのレッスンもできます。

2. 人間の講師と使う

各レッスンには時間配分・講師用メモ・モデル対話・ドリルの答えがそろっています。講師はこのページを開きながら進行できます。

3. ひとりで予習・復習する

単語表と表現パターンを音読し、ロールプレイの Ken のセリフを声に出して練習。レッスンページのタイマーで 30 分の流れを体感できます。

Claude Code でレッスンを始める手順

  1. リポジトリを clone する
    git clone https://github.com/ke-iwata/english-lerning.git && cd english-lerning
  2. Claude Code を起動する
    claude
  3. レッスン番号を指定して開始する
    /lesson 01
  4. 声で話したいときは、Claude Code の音声入力をオンにして、voice を付けて始める(講師の返答が読み上げられます。macOS は追加インストール不要)
    /voice tap
    /lesson 01 voice

    Space を押して話し、もう一度押すと送信。詳しい設定は VOICE.md。

  5. 終了後、Claude が progress/sessions/ に記録(良かった点・直す点・弱い単語・宿題)を書いてコミットします。次回はその記録を読んでから始まるので、レッスンがつながります。復習は /review、自由会話は /freetalk。

レッスン中は、英語で話すのが基本ですが、分からないときは日本語で「ヒント」「もう一回」「日本語で」「終了」と言えば、講師(Claude)が日本語で助けてくれます。 Claude Code 以外(claude.ai のアプリなど)で使うときは、各レッスンページの「Claude 用プロンプトをコピー」を押して貼り付けてください。プロンプトの詳細は prompts/ にあります。
