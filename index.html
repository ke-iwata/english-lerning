30分で身につける、仕事で使える英会話

中学英語が多少わかるレベルから、会議・報告・依頼・交渉・面接まで。単語・イディオム・表現パターン・ロールプレイを 30 分に凝縮した、講師付き 1on1 レッスン用のテキストです。 Claude Code を講師にして、そのまま実践レッスンができます。

使い方

1. Claude アプリの音声モードで(おすすめ)

Claude アプリの Project に講師インストラクションと教材を入れ、音声モードで会話。Claude が声で質問し、相手役を演じ、間違いを直します。スマホでも PC でも。設定手順

2. Claude Code を講師にする

リポジトリを clone して claude を起動し、/lesson 01 と打つだけ。テキスト(または音声入力)で 30 分のレッスンを進行し、終了後に記録を自動でコミットします。

3. 人間の講師と / ひとりで

各レッスンには時間配分・講師用メモ・モデル対話・ドリルの答えがそろっているので、人間の講師との 1on1 にもそのまま使えます。ひとりなら単語表と Ken のセリフを音読し、タイマーで 30 分の流れを体感。

Claude Code でレッスンを始める手順(テキスト中心)

  1. リポジトリを clone する
    git clone https://github.com/ke-iwata/english-lerning.git && cd english-lerning
  2. Claude Code を起動する
    claude
  3. レッスン番号を指定して開始する
    /lesson 01
  4. Claude Code でも声で受けたい場合は /voice tap(音声入力)と /lesson 01 voice(返答の読み上げ)。詳細は VOICE.md。
  5. 終了後、Claude が progress/sessions/ に記録(良かった点・直す点・弱い単語・宿題)を書いてコミットします。次回はその記録を読んでから始まるので、レッスンがつながります。復習は /review、自由会話は /freetalk。

レッスン中は、英語で話すのが基本ですが、分からないときは日本語で「ヒント」「もう一回」「日本語で」「終了」と言えば、講師(Claude)が日本語で助けてくれます。 Project を作らずに 1 回だけ試すなら、各レッスンページの「Claude 用プロンプトをコピー」を Claude アプリに貼り付けてから音声モードに入ってもレッスンできます。プロンプトの詳細は prompts/ にあります。

Claude と声でレッスンする(Claude アプリの音声モード)

Claude アプリ(iOS / Android / デスクトップ / Web)の音声モードで、Claude を講師にします。初回だけ Project を作れば、あとは「Lesson 03」と言って話すだけ。

  1. 教材ファイルをダウンロード(Claude の Project に入れるファイル)
    00 講師インストラクション 01 カリキュラム Level 1 Level 2 Level 3 Level 4 全レッスン(1 ファイル)
  2. Claude アプリで Project を作る — Projects → New Project。「Set project instructions」に 00 講師インストラクション の中身を貼り付け、Project knowledge に 01 カリキュラム と Level 1〜4(または全レッスン)をアップロード。
  3. レッスンを始める — Project 内で新しいチャットを開き、テキストで Lesson 01 と送ってから、入力欄の右の音波アイコンで音声モードに入る。あとは声で会話。「ヒント」「もう一回」「日本語で」「終了」は日本語で OK。
  4. 記録を残す — 終わったら音声モードを止め、テキストで「記録を作って」。出てきた記録をコピーして、リポジトリの Claude Code で /log(保存・コミット・次回用の progress-pack を生成)。生成された progress-pack.md を Project knowledge に入れておくと、次回は前回の弱点と宿題を踏まえて始まります。

詳しい手順とトラブル対処は VOICE.md。音声モードはターン制なので、言い終えたら少し間を置くか、プッシュトゥトークにすると快適です。
