# Lesson 05: 丁寧な依頼とお願い
## Making Polite Requests

> **Can-do:** 相手や状況に合わせた丁寧さで、依頼・お願い・許可の確認ができ、依頼を受けたり断ったりできる
> **Level:** 1 ・ **Time:** 30 min ・ **Scenario:** 同僚のMikeにコードレビューと資料の共有を依頼する

<details>
<summary>講師用メモ (Tutor Notes)</summary>

- **このレッスンのゴール:** `Can you` → `Could you` → `Would you mind -ing` の 3 段階の丁寧さを使い分け、依頼に「理由」と「期限」を添えられる。受けるとき・断るときの決まり文句も言える。
- **進め方のポイント:** 日本人学習者は `Please + 動詞` を丁寧だと思いがちだが、実際は指示に近い。「Please は命令形に化粧をしただけ」と伝え、`Could you ... ?` を基本形にする。Warm-up では前回の宿題(今週の予定 3 つ)を聞く。
- **よく出るつまずき:**
  - `Would you mind to review ...` → 「mind の後は -ing」と日本語で一言
  - `Would you mind ...?` に `Yes.` と答えて「嫌です」になってしまう → 「OK なら No / Not at all / Sure, go ahead」
  - 断るとき `No, I can't.` だけで終わる → 「理由 + 代案」をセットで: `I'm tied up now. Can I do it at 3?`
  - 依頼に理由を付けない → `because ...` / `It's for the release on Friday.`
- **日本語ヒントの例:** 「もう少し丁寧に: Could you ...?」「理由を足そう: because ...」「いつまでか言おう: by tomorrow?」「断るなら代案も: How about tomorrow morning?」
- **余裕があれば:** Challenge の「上司(Sarah)に休暇の許可をもらう」で、`I was wondering if I could ...` のいちばん丁寧な形まで使わせる。
- **時間が足りなければ:** Pattern 3(許可)は例文を読むだけにして Drill 4 番を飛ばし、Variation B を省略。

</details>

## 1. Warm-up (3 min)

講師が質問し、学習者は 1〜2 文で答えます。短くて OK。完璧でなくて OK。

1. Tell me three things on your schedule this week, with the day and time. (前回の宿題: 今週の予定 3 つ)
2. Who do you usually ask for a code review? (ふだん誰にコードレビューを頼みますか?)
3. What was the last thing you asked a colleague to do? (最近、同僚に何を頼みましたか?)

<details><summary>例 / Sample answers</summary>

1. I have a team meeting on Tuesday at 10 a.m. The release is on Friday at 6 p.m. ...
2. I usually ask Mike. He knows the payment code well.
3. I asked him to check my pull request.

</details>

## 2. Vocabulary & Idioms (7 min)

### Words

| English | 日本語 | Example |
|---|---|---|
| favor | 頼みごと | Can I ask you a favor? |
| review | レビュー(する) | Could you review my pull request? |
| share | 共有する | Could you share the design document? |
| urgent | 急ぎの | It's urgent. The release is tomorrow. |
| access | アクセス権 | I need access to the staging server. |
| permission | 許可 | I need permission from Sarah. |
| remind | 思い出させる | Could you remind me tomorrow morning? |
| instead | 代わりに | Can we do it tomorrow instead? |

### Idioms & Collocations

| English | 日本語 | Example |
|---|---|---|
| take a look at ... | 〜にざっと目を通す | Could you take a look at this PR? |
| when you have a moment | 手が空いたときに | When you have a moment, could you check this? |
| be tied up | 手が離せない | I'm tied up until 3 p.m. |
| no problem | 問題ないよ・いいよ | "Can you help me?" "Sure, no problem." |

**発音・使い方の注意:**
- `favor` は **FAY**-ver。`Can I ask you a favor?` は頼みごとの前置きとして万能。
- `Could you ...?` の `could` は「クッジュ」のようにつながる。`Would you mind ...?` の mind の後は必ず **-ing**(mind reviewing)。
- `urgent` は本当に急ぎのときだけ使う。毎回使うと信用されなくなる。軽い依頼は `when you have a moment` を添えると柔らかい。

### Quick check

講師が日本語で言い、学習者が英語で即答します(5〜6問)。

- 「頼みごとをしてもいい?」 → Can I ask you a favor?
- 「この PR にざっと目を通してもらえますか?」 → Could you take a look at this PR?
- 「手が空いたときに」 → when you have a moment
- 「今、手が離せません」 → I'm tied up right now.
- 「代わりに明日でもいいですか?」 → Can we do it tomorrow instead?
- 「ステージングサーバーへのアクセス権が必要です」 → I need access to the staging server.

## 3. Key Expressions (7 min)

### Pattern 1: 基本の依頼(軽い → 丁寧) — Can you ...? / Could you ...?

- Can you check this quickly? (同僚に、軽く)
- Could you review my pull request by tomorrow? (少し丁寧)

### Pattern 2: さらに丁寧に — Would you mind -ing? / I was wondering if you could ...

- Would you mind sharing the design document?
- I was wondering if you could join the demo on Friday.

### Pattern 3: 許可をもらう — Can I ...? / Is it OK if I ...?

- Can I use the staging server this afternoon?
- Is it OK if I leave early today? I have a doctor's appointment.

### Pattern 4: 受ける・断る — Sure, no problem. / I'm afraid I can't ... right now.

- Sure, no problem. I'll do it after lunch.
- I'm afraid I can't right now. I'm tied up until 3. How about 3:30?

**Drill:** 日本語を見て、英語で言ってみましょう。

1. 頼みごとをしてもいい? 私のプルリクエストをレビューしてもらえますか?
2. 手が空いたときに、API の資料を共有してもらえませんか?(Would you mind で)
3. 急ぎです。リリースが明日なので。
4. 今日、少し早く帰ってもいいですか?
5. 申し訳ないけど、今は手が離せません。明日の朝ではどうですか?

<details><summary>Answers</summary>

1. Can I ask you a favor? Could you review my pull request?
2. When you have a moment, would you mind sharing the API document?
3. It's urgent, because the release is tomorrow.
4. Is it OK if I leave a little early today?
5. I'm afraid I can't right now. I'm tied up. How about tomorrow morning?

</details>

### よくある間違い (Common mistakes)

| ✗ | ✓ | なぜ |
|---|---|---|
| Please review my code. | **Could you** review my code? | Please + 命令形は「指示」に聞こえる。依頼は疑問文で |
| Would you mind to review this? | Would you mind **reviewing** this? | mind の後は動名詞(-ing) |
| "Would you mind helping me?" "Yes!" | "**No, not at all.**" / "**Sure, go ahead.**" | Yes = 「嫌です(気にします)」の意味になる |
| Can you borrow me your laptop? | Can you **lend** me your laptop? / Can I **borrow** your laptop? | borrow は「借りる」、lend は「貸す」 |

## 4. Role-play (10 min)

### Scenario

金曜日に決済 API のリリースがあります。今日は水曜日。あなた(Ken)はプルリクエストを出したところですが、レビューがまだです。US チームの同僚 Mike にレビューを頼み、ついでに Mike が持っている設計資料(design document)も共有してもらいましょう。Mike は今日忙しそうです。

### Roles

- **Ken (you):** Sakura Tech のバックエンドエンジニア。PR #512 のレビューを今日中にもらいたい。設計資料も必要。
- **Mike (tutor):** US チームの同僚エンジニア。親切だが、今日は午後 3 時まで別の作業で手が離せない。

### Model dialogue

まず講師と一緒に読みます。次に学習者が Ken の行を、見ないで言ってみます。

**Ken:** Hi Mike, do you have a minute? Can I ask you a favor?
**Mike:** Sure, what's up?
**Ken:** Could you review my pull request today? It's PR 512, the payment API.
**Mike:** Today? Hmm, I'm tied up until 3 p.m. Is it urgent?
**Ken:** Yes, a little. The release is on Friday, so I need the review by tomorrow.
**Mike:** OK, got it. I can take a look at it after 3. Is that OK?
**Ken:** That's perfect. Thank you.
**Mike:** No problem. Anything else?
**Ken:** Actually, yes. Would you mind sharing the design document for the new queue?
**Mike:** The design doc? Sure. I'll send you the link on Slack.
**Ken:** Thanks. And one more thing. Is it OK if I use the staging server this afternoon?
**Mike:** Sorry, I'm using it until 2. Can you use it after 2 instead?
**Ken:** Sure, after 2 is fine. Thanks a lot, Mike.
**Mike:** Anytime. Good luck with the release.

### Your turn

モデル対話を参考に、自分の言葉で。講師は Mike 役をしながら、必要なら日本語でヒントを出します。

- **Variation A:** 自分の本当の仕事で、同僚に 2 つ頼みごとをする(レビュー、資料、テストの手伝いなど)。Mike は途中で **"Sorry, I can't today. I'm off this afternoon. Can it wait until tomorrow?"** と断ってくるので、期限を説明して代案を出す(例: Tomorrow morning is OK. Could you do it first thing?)。
- **Variation B:** 立場を逆にする。**Mike が Ken に** "Could you help me with the database migration today?" と頼んでくる。Ken は今日はリリース準備で忙しいので、**理由と代案を添えて丁寧に断る**(I'm afraid I can't today. How about Monday?)。Mike は "Just 30 minutes?" とさらに頼んでくる。

### Challenge (余裕があれば)

上司役の **Sarah** に、来週金曜日の休暇の許可をもらいましょう。いちばん丁寧な形を使い、理由と、仕事への影響がないことを伝えます。

- I was wondering if I could take next Friday off. It's a family event.
- The release will be done by Thursday, so it won't affect the schedule.

## 5. Wrap-up (3 min)

### Self-check

- [ ] `Could you ...?` で依頼し、理由と期限を添えられた
- [ ] `Would you mind -ing?` を -ing で正しく言えた
- [ ] `Is it OK if I ...?` で許可を求められた
- [ ] 依頼を `Sure, no problem.` で受け、`I'm afraid I can't ...` + 代案で断れた

### Homework

今週、同僚や家族に英語で 1 つ頼みごとをしてみる(Slack の英語チャンネルでも OK)。難しければ、実際に頼む予定の依頼を 3 つ、`Could you ... by ...? It's for ...` の形で書いて 3 回音読。次回の Warm-up で 1 つ言ってもらいます。
