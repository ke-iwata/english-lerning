# Lesson 08: 進捗報告(デイリースタンドアップ)
## Giving Status Updates

> **Can-do:** 昨日やったこと・今日やること・困っていることを、スタンドアップで簡潔に報告できる
> **Level:** 2 ・ **Time:** 30 min ・ **Scenario:** 海外チームとのデイリースタンドアップで進捗を報告する

<details>
<summary>講師用メモ (Tutor Notes)</summary>

- **このレッスンのゴール:** 「昨日(過去形)→ 今日(be going to / will)→ 困りごと(I'm blocked on ... / No blockers.)」の 3 点を、メモを見ずに 1 分以内で言える。さらに、PM からの「間に合う?」という質問に見通し(by + 曜日、on track / behind)で答えられる。
- **進め方のポイント:** スタンドアップは「短く・具体的に」が命。長く話しすぎたら "Keep it short" と止めて OK。時制の切り替え(昨日=過去形、今日=未来)を Drill で体に入れてから Role-play に進む。Role-play では講師が Sarah と Mike の 2 役を演じる(声色や「— Mike:」と前置きして区別)。
- **よく出るつまずき:**
  - 昨日のことを現在形・進行形で言う(✗ Yesterday I am fixing)→ 「昨日は過去形: fixed, finished, worked on」
  - 期限の `until` と `by` の混同 → 「締め切りは by」
  - 「ブロッカーなし」が出てこない → "No blockers." の 2 語でいいと伝える
  - 「待っています」で `for` が抜ける → "waiting **for** ..."
- **日本語ヒントの例:** 「昨日やったことから: Yesterday, I ...」「今日は: Today, I'm going to ...」「困ってることは? なければ No blockers.」「いつ終わりそう? It should be done by ...」
- **余裕があれば:** Challenge の「メモなし 45 秒 + 数字を 1 つ入れる」。さらに、欠席者の分を代わりに報告する(Variation B の後半)。
- **時間が足りなければ:** Pattern 4(見通し)の Drill を省略し、Role-play は Model dialogue + Variation A のみ。

</details>

## 1. Warm-up (3 min)

講師が質問し、学習者は 1〜2 文で答えます。短くて OK。完璧でなくて OK。

1. Last time we practiced scheduling. Propose a meeting time for tomorrow. (前回の復習: 明日のミーティングの時間を提案してみてください)
2. What did you work on yesterday? (昨日は何をしましたか?)
3. Does your team have a daily standup? What time is it? (チームにデイリースタンドアップはありますか?)

<details><summary>例 / Sample answers</summary>

1. How about tomorrow at 10 a.m. JST? Does that work for you?
2. I worked on the login API. I also reviewed Mike's PR.
3. Yes, we have one at 10 a.m. It's about 15 minutes.

</details>

## 2. Vocabulary & Idioms (7 min)

### Words

| English | 日本語 | Example |
|---|---|---|
| progress | 進捗 | I made good progress on the API yesterday. |
| blocker | ブロッカー(作業を止めているもの) | I have one blocker. I'm waiting for access. |
| ticket | チケット(タスク) | I'm working on ticket PAY-123 today. |
| estimate | 見積もり・見積もる | My estimate is two more days. |
| delay | 遅れ・遅らせる | There's a small delay on the search feature. |
| priority | 優先度 | What's the priority for this bug? |
| merge | マージする | I merged the PR this morning. |
| release | リリース | The release is planned for Thursday. |

### Idioms & Collocations

| English | 日本語 | Example |
|---|---|---|
| be on track | 予定どおり進んでいる | The payment feature is on track for Friday. |
| be behind schedule | 予定より遅れている | I'm a day behind schedule on the tests. |
| wrap up | 仕上げる・終わらせる | I'll wrap up the refactoring today. |
| pick up | (タスクを)取る・着手する | I'll pick up the next ticket after that. |

**発音・使い方の注意:**
- `progress` は数えられない名詞。✗ a progress → ✓ some progress / good progress。"make progress" で覚える。
- `estimate` は名詞なら **ES**-ti-mit、動詞なら **ES**-ti-mate(語尾の母音が変わる)。
- 「順調です」は "It's on track." / "I'm on track."、「遅れています」は "I'm behind schedule." どちらも be 動詞。
- 時制の切り替えが報告の骨格: 昨日 = 過去形、今日 = be going to / will、困りごと = 現在形(I'm blocked on ...)。

### Quick check

講師が日本語で言い、学習者が英語で即答します(5〜6問)。

- 「進捗」 → progress
- 「予定どおりです」 → It's on track.
- 「1日遅れています」 → I'm a day behind schedule.
- 「今日中に仕上げます」 → I'll wrap it up today.
- 「次のチケットに着手します」 → I'll pick up the next ticket.
- 「ブロッカーはありません」 → No blockers.

## 3. Key Expressions (7 min)

### Pattern 1: 昨日 — Yesterday, I ... (過去形)

- Yesterday, I finished the login API and merged the PR.
- Yesterday, I worked on the search bug, but it's not fixed yet.

### Pattern 2: 今日 — Today, I'm going to ... / I'll ...

- Today, I'm going to write tests for the payment flow.
- Today, I'll pick up ticket PAY-130 and review Mike's PR.

### Pattern 3: 困りごと — I'm blocked on ... / I'm waiting for ... / No blockers.

- I'm blocked on the database access. I'm waiting for Sarah's approval.
- No blockers for now.

### Pattern 4: 見通し — It should be done by ... / I'm about ... done.

- It should be done by Thursday.
- I'm about 70% done. It's on track for the release.

**Drill:** 日本語を見て、英語で言ってみましょう。

1. 昨日はログイン API を終えて、PR をマージしました。
2. 今日は決済フローのテストを書きます。
3. Mike のレビュー待ちで止まっています。
4. ブロッカーはありません。順調です。
5. 木曜までには終わるはずです。

<details><summary>Answers</summary>

1. Yesterday, I finished the login API and merged the PR.
2. Today, I'm going to write tests for the payment flow.
3. I'm blocked on Mike's review. / I'm waiting for Mike's review.
4. No blockers. It's on track.
5. It should be done by Thursday.

</details>

### よくある間違い (Common mistakes)

| ✗ | ✓ | なぜ |
|---|---|---|
| Yesterday I am fixing the bug. | Yesterday I **fixed** the bug. | 昨日のことは過去形。日本語の「〜していました」につられない |
| I will finish it until Friday. | I will finish it **by** Friday. | 期限は by。until は「〜までずっと(続く)」 |
| I'm waiting Mike's review. | I'm waiting **for** Mike's review. | wait には for が必要 |
| I have a progress. | I made **some** progress. | progress は数えられない。make progress で覚える |

## 4. Role-play (10 min)

### Scenario

毎朝 10 時(JST)の Zoom スタンドアップ。参加者は Sarah(進行役)、Mike、そしてあなた(Ken)。順番は Mike → Ken。あなたは Lesson 07 で仕様確認した決済 API の変更を実装中で、リリースは木曜日。Sarah は木曜に間に合うかを気にしています。

### Roles

- **Ken (you):** 決済 API の変更を実装中。昨日: エラーハンドリングを実装して PR を作成。今日: テストを追加。Mike のレビュー待ち。木曜のリリースには少しぎりぎり。
- **Sarah (tutor):** 進行役の PM。木曜のリリースが気になっている。短く具体的な答えを求める。
- **Mike (tutor):** 同僚エンジニア。Ken の PR をまだ見ていない。

### Model dialogue

まず講師と一緒に読みます。次に学習者が Ken の行を、見ないで言ってみます。

**Sarah:** OK, let's start. Mike, you go first.
**Mike:** Sure. Yesterday I fixed the search bug and deployed it to staging. Today I'll look at the logging issue. No blockers.
**Sarah:** Thanks. Ken?
**Ken:** Yesterday, I implemented the error handling for the payment API and opened a PR.
**Sarah:** Nice. And today?
**Ken:** Today, I'm going to add tests. I'm also waiting for a review on the PR.
**Mike:** Sorry, I haven't looked at it yet. I'll review it after this meeting.
**Ken:** Thanks, Mike. That would be great.
**Sarah:** Will it be ready for the release on Thursday?
**Ken:** I think so. I'm about 70% done. If the review is done today, it should be on track.
**Sarah:** OK. Let me know right away if anything changes.
**Ken:** Will do.

### Your turn

モデル対話を参考に、自分の言葉で。講師は Sarah と Mike の 2 役をしながら、必要なら日本語でヒントを出します。

- **Variation A:** Ken は **1 日遅れています**(テストでバグが見つかった)。昨日・今日・新しい見通しを正直に報告する。Sarah は **"What can we do to speed it up? Should Mike help?"** と聞いてくるので、Mike に手伝ってもらうか、自分で間に合わせるか、その場で判断して答える。
- **Variation B:** Mike が先に **"I can't test my part until Ken's endpoint is ready."** と、Ken の API 待ちでブロックされていると報告します。Ken は自分の報告の中で、いつ使えるようになるかを答える。その後 Sarah が **"Yuki is out sick today. Can you give her update?"** と、欠席した同僚 Yuki の分も聞いてくるので、知っている範囲で答える(分からなければ "I'm not sure. I'll check and post it in Slack." で OK)。

### Challenge (余裕があれば)

メモを見ずに、45 秒で今日の自分の報告をする。条件: 数字を 1 つ入れる(〜%、〜日、チケット番号など)。言い終わったら、講師が 1 つ質問をするので、それにも答える。

- 例: "I'm about 80% done." / "It'll take two more days." / "I closed three tickets."

## 5. Wrap-up (3 min)

### Self-check

- [ ] 昨日・今日・困りごとの 3 点を、順番に 1 分以内で言えた
- [ ] 昨日は過去形、今日は be going to / will で言い分けられた
- [ ] I'm blocked on ... / I'm waiting for ... / No blockers. が言えた
- [ ] 見通しを by + 曜日、または on track / behind schedule で言えた

### Homework

明日の自分のスタンドアップの内容(実際のものでも想像でも OK)を英語で 3 文書き、声に出して 3 回読む。次回の Warm-up で、見ないで言ってもらいます。
