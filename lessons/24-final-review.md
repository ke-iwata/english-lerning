# Lesson 24: 総合演習:海外チームとの1日
## Final Review: A Day with the Global Team

> **Can-do:** これまでの表現を組み合わせ、スタンドアップ・相談・交渉・雑談を含む一連の場面を英語でこなせる
> **Level:** 4 ・ **Time:** 30 min ・ **Scenario:** スタンドアップから夕方の1on1まで、海外チームとの1日を通しでシミュレーションする

<details>
<summary>講師用メモ (Tutor Notes)</summary>

- **このレッスンのゴール:** 新しい表現を覚えるのではなく、これまでの 23 レッスンの表現を「場面が切り替わっても」使い続けられること。1 日の 4 場面(スタンドアップ → 相談 → クライアント交渉 → 1on1 の雑談)を途切れずに通す。
- **進め方のポイント:** 今回は Vocabulary も Key Expressions も復習中心なので、2・3 のセクションはテンポよく進め、Role-play に 10 分をしっかり確保する。場面の切り替えは講師が "OK, it's now 2 p.m. Ms. Lee joins the call." のようにナレーションで区切る。Ken が止まったら、どのレッスンの表現かをヒントにする(例: 「Lesson 10 の『試したこと』の言い方」)。
- **よく出るつまずき:**
  - スタンドアップで「困っていること」が出ない → 「Lesson 08: I'm blocked by ... / I need help with ...」
  - 相談で状況説明が長くなる → 「Lesson 10 の順番: 何が起きた → 試したこと → 欲しい助け」
  - 交渉で「ノー」が言えず全部受けてしまう → 「Lesson 18: We can do A by Friday, but B would need another week.」
  - 1on1 で仕事の話だけになる → 「Lesson 03 の雑談から入る: How was your weekend?」
- **日本語ヒントの例:** 「"確認ですが" は Just to confirm, ...(L21)」「"もっともです" は Fair point.(L19)」「"現時点では" は As of now, ...(L20)」
- **余裕があれば:** Challenge の「1 日の終わりに Sarah へ 3 行の Slack まとめを口頭で作る」。さらに余裕があれば、苦手だったレッスンの Variation をもう一度やる。
- **時間が足りなければ:** Vocabulary の Quick check を 3 問にし、Key Expressions は Drill を省いて例文を読むだけにする。Role-play の Scene 4(1on1)は短く 2 往復で終える。

</details>

## 1. Warm-up (3 min)

講師が質問し、学習者は 1〜2 文で答えます。最終回なので、前回の宿題「カンファレンス用 20 秒自己紹介」から始めます。

1. Give me your 20-second conference introduction from last time's homework.
2. Looking back at the 23 lessons, which one was the hardest for you? Why?
3. What's one English phrase you've actually used at work since we started?

<details><summary>例 / Sample answers</summary>

1. Hi, I'm Ken, a backend engineer at Sakura Tech. I work on the payment API, and I'm into observability these days.
2. The incident report lesson. It's hard to stay calm and structured at the same time.
3. "Just to confirm, ..." I use it in almost every meeting now.

</details>

## 2. Vocabulary & Idioms (7 min)

今回は新出語を減らし、これまでの重要語を「使えるか」の確認が中心です。表の * が付いたものは新出(2 語・1 表現)、それ以外は復習です。

### Words

| English | 日本語 | Example |
|---|---|---|
| blocker (L19) | 作業を止めている問題 | My only blocker is the missing test data. |
| root cause (L20) | 根本原因 | We're still looking for the root cause. |
| scope (L21) | 範囲 | That change is out of scope for this sprint. |
| trade-off (L09/L18) | 一長一短・トレードオフ | There's a trade-off between speed and safety. |
| estimate (L18) | 見積もり | My estimate is about two weeks. |
| priority (L21) | 優先順位 | What's the priority: the bug fix or the new feature? |
| wrap up * | 締めくくる・終える | Let's wrap up here and continue tomorrow. |
| takeaway * | 要点・持ち帰るべき学び | My main takeaway is that we need better monitoring. |

### Idioms & Collocations

| English | 日本語 | Example |
|---|---|---|
| be blocked by ... (L08) | 〜で作業が止まっている | I'm blocked by the API key issue. |
| keep you posted (L20) | 随時お知らせする | I'll keep you posted after the deploy. |
| on the same page (L21) | 認識が合っている | Let's make sure we're on the same page before I start. |
| touch base * | 軽く連絡を取る・状況を合わせる | Let's touch base again on Friday. |

**発音・使い方の注意:**
- `takeaway` は **TAKE**-a-way。会議の最後に `Key takeaways are ...` と言うとまとめが締まる。
- `wrap up` は「(会議・仕事を)終える」。`Let's wrap up.` で「そろそろ終わりましょう」。宿題の `Wrap-up` と同じ語。
- `touch base` は Slack や 1on1 で非常によく使う。`touch base with 人` / `touch base on 話題`。

### Quick check

講師が日本語で言い、学習者が英語で即答します(5〜6問)。

- 「テストデータがなくて作業が止まっています」 → I'm blocked by the missing test data.
- 「それは今回のスプリントの範囲外です」 → That's out of scope for this sprint.
- 「私の見積もりは約 2 週間です」 → My estimate is about two weeks.
- 「金曜にまた状況を合わせましょう」 → Let's touch base again on Friday.
- 「要点は、監視の改善が必要ということです」 → The main takeaway is that we need better monitoring.
- 「そろそろ締めましょう」 → Let's wrap up.

## 3. Key Expressions (7 min)

今日のパターンは、1 日の 4 場面にそれぞれ対応しています。どれも以前のレッスンで学んだものです。

### Pattern 1: スタンドアップ(L08)— Yesterday I ... / Today I'm going to ... / I'm blocked by ...

- Yesterday I finished the retry logic. Today I'm going to write the tests.
- I'm blocked by the staging database. It's been down since this morning.

### Pattern 2: 相談(L10 + L06)— I've tried ... but ... / Could you take a look at ...?

- I've tried restarting the worker, but the queue is still growing.
- Could you take a look at the config with me? I might be missing something.

### Pattern 3: 交渉と要件確認(L18 + L21)— We can do A by ..., but B would need ... / Just to confirm, ...

- We can deliver the export by Friday, but the dashboard would need another week.
- Just to confirm, the CSV is the must-have, and the dashboard can wait. Is that right?

### Pattern 4: 雑談と 1on1(L03 + L09)— How was your ...? / I feel ... / One thing I'd like to improve is ...

- How was your weekend? Did you do anything fun?
- Honestly, I feel the on-call load is a bit heavy. One thing I'd like to improve is the alerting.

**Drill:** 日本語を見て、英語で言ってみましょう。

1. 昨日はリトライ処理を終えました。今日はテストを書きます。
2. ワーカーを再起動してみましたが、キューはまだ増え続けています。
3. エクスポートは金曜までにできますが、ダッシュボードはもう 1 週間必要です。
4. 確認ですが、CSV が必須で、ダッシュボードは後でもよい、ということですね?
5. 正直なところ、オンコールの負荷が少し重いと感じています。

<details><summary>Answers</summary>

1. Yesterday I finished the retry logic. Today I'm going to write the tests.
2. I've tried restarting the worker, but the queue is still growing.
3. We can deliver the export by Friday, but the dashboard would need another week.
4. Just to confirm, the CSV is the must-have, and the dashboard can wait, right?
5. Honestly, I feel the on-call load is a bit heavy.

</details>

### よくある間違い (Common mistakes)

これまでのレッスンで何度も出た、場面が変わっても繰り返しやすいものです。

| ✗ | ✓ | なぜ |
|---|---|---|
| Yesterday I did the retry. Today also retry. | Yesterday I finished the retry logic. Today I'm going to test it. | 動詞を省くと報告にならない。`finished / I'm going to` をはっきり |
| It doesn't work. (相談の第一声) | The queue keeps growing. I've tried restarting, but it didn't help. | 「動かない」だけでは相手が助けられない。状況 + 試したこと(L10) |
| Yes, OK, we can do everything. | We can do A by Friday, but B would need another week. | 全部受けると後で困る。条件つきで Yes(L18) |
| (1on1 で)No problem. Everything is fine. | Honestly, one thing I'd like to improve is ... | 1on1 は本音を言う場。`Honestly, ...` で切り出す(L09) |

## 4. Role-play (10 min)

### Scenario

海外チームとの、ある水曜日。朝のスタンドアップから夕方の 1on1 まで、4 つの場面を**続けて**演じます。講師は場面の切り替えを英語でナレーションし、Sarah・Mike・Ms. Lee を演じ分けます。途中で止まっても、前の場面に戻らず次へ進みます。

- **Scene 1 (10:00) スタンドアップ:** Sarah・Mike と進捗共有。Ken はステージング DB の問題で作業が止まっている。
- **Scene 2 (11:00) 相談:** Mike にステージング DB の問題を相談する。
- **Scene 3 (14:00) クライアント交渉:** Ms. Lee が「レポート機能のリリースを 1 週間早めてほしい」と言ってくる。
- **Scene 4 (17:00) 1on1 の雑談:** Sarah との 1on1。週末の話から入り、オンコールの負荷について本音を話す。

### Roles

- **Ken (you):** Sakura Tech のバックエンドエンジニア。今週はレポート機能(週次 CSV エクスポート)の開発中。昨日リトライ処理を完了、今日はテストを書く予定だが、ステージング DB が朝から落ちていて止まっている。CSV は金曜に出せるが、ダッシュボードはあと 1 週間必要。週末は家族と鎌倉へ行った。オンコールのアラートが多すぎると感じている。
- **Sarah (tutor):** PM。スタンドアップの進行役。1on1 では聞き役で、Ken の本音を引き出したい。
- **Mike (tutor):** 同僚エンジニア。ステージング DB の障害の原因(ディスクフル)を知っている。
- **Ms. Lee (tutor):** クライアント。レポート機能を 1 週間前倒しでほしいが、CSV だけなら納得する。

### Model dialogue

まず講師と一緒に読みます。次に学習者が Ken の行を、見ないで言ってみます。

*— Scene 1: Daily standup, 10:00 —*

**Sarah:** Morning, everyone. Ken, could you go first?
**Ken:** Sure. Yesterday I finished the retry logic for the export job. Today I'm going to write the tests.
**Sarah:** Any blockers?
**Ken:** Yes, one. I'm blocked by the staging database. It's been down since this morning.
**Mike:** Oh, I saw that too. Let's touch base after standup.

*— Scene 2: Asking Mike for help, 11:00 —*

**Ken:** Hey Mike, do you have a minute? It's about the staging DB.
**Mike:** Sure. What's going on?
**Ken:** Connections time out. I've tried restarting the service, but it didn't help. Could you take a look with me?
**Mike:** I checked the logs earlier. The disk is full. Someone left debug logging on.
**Ken:** That explains it. So if I turn off debug logging and clear the old logs, it should recover?
**Mike:** Exactly. I'll help you clear them now.

*— Scene 3: Call with Ms. Lee, 14:00 —*

**Ms. Lee:** Ken, thanks for joining. We'd like the report feature one week earlier than planned.
**Ken:** I understand it's important. Just to confirm, you need both the CSV export and the dashboard?
**Ms. Lee:** Ideally, yes.
**Ken:** We can deliver the CSV by this Friday, but the dashboard would need another week. Would the CSV alone work for your Monday meeting?
**Ms. Lee:** Hmm. Yes, the CSV is the must-have. The dashboard can wait.
**Ken:** Great. Then let's do that. I'll keep you posted on Friday.

*— Scene 4: 1on1 with Sarah, 17:00 —*

**Sarah:** How was your weekend, Ken?
**Ken:** It was nice. I took my family to Kamakura. How about you?
**Sarah:** Lovely. I mostly rested. So, how are things going?
**Ken:** Mostly fine. Honestly, though, I feel the on-call load is a bit heavy. One thing I'd like to improve is the alerting.
**Sarah:** Fair point. Can you bring a proposal to next week's tech sync?
**Ken:** Yes, I'll put something together. Let's wrap up here, and I'll send you my notes.

### Your turn

モデル対話を参考に、自分の言葉で。講師は Sarah・Mike・Ms. Lee を演じ分けながら、必要なら日本語でヒントを出します。4 つの場面を通しで行います。

- **Variation A:** 内容は Model dialogue と同じだが、各場面に一つずつ予想外の一言が入る。Scene 1 で Sarah が **"Sorry, which job did you say? The export or the import?"** と聞き返す。Scene 2 で Mike が **"Actually, I'm not sure that's the cause. Can you check the disk usage yourself?"** と手を離す。Scene 3 で Ms. Lee が **"Can't you just add more engineers?"** と無理を言う。Scene 4 で Sarah が **"On a scale of one to ten, how is your workload?"** と数字で聞いてくる。
- **Variation B:** 設定を自分の実際の仕事に置き換える(今やっているタスク、本当に困っていること、実際のクライアントの要望)。Scene 3 では、Ms. Lee が納期ではなく **「機能の追加」(And we also need it in Excel format, not CSV.)** を要求してくるので、スコープと見積もりの話に持ち込む。

### Challenge (余裕があれば)

1 日の終わりに、Sarah へ送る Slack の 3 行アップデート(Done / Blocked → Resolved / Next)を口頭で組み立ててみましょう。

- Done: finished the retry logic, agreed with Ms. Lee on a CSV-only release by Friday.
- Blocked: staging DB was down (disk full). Resolved with Mike at 11:30.
- Next: write the export tests tomorrow, and draft an alerting proposal for the tech sync.

## 5. Wrap-up (3 min)

### Self-check

- [ ] スタンドアップで「昨日・今日・ブロッカー」を 3 文で言えた
- [ ] 相談で「状況 → 試したこと → 欲しい助け」の順に説明できた
- [ ] 交渉で全部受けずに `We can do A by ..., but B would need ...` と条件つきで答えられた
- [ ] 1on1 で雑談から入り、`Honestly, ...` で本音を一つ言えた

### Homework

24 レッスンの Self-check を見返して、チェックが付かなかった項目を 3 つ選び、その表現を使った英文を各 2 つ書く。さらに、今週の実際の会議か Slack で、そのうち 1 つを本当に使ってみる。
