# レッスン執筆ガイド (Authoring Guide)

このファイルは、各レッスン(`lessons/NN-slug.md`)を書く・直すときのルールです。
すべてのレッスンは **同じ構成・同じ見出し・同じ時間配分** にそろえます。
これは Web サイトの表示と、Claude Code が講師としてレッスンを進行するときの両方で前提になります。

## 対象学習者

- 中学英語が多少身についているレベルからスタート(be動詞・一般動詞・過去形・疑問文は知っている)
- 目標:ビジネスで必要な英語力(会議・報告・依頼・交渉・面接)
- 職業は主にソフトウェアエンジニア(バックエンド)。例文やロールプレイは IT 企業の現場を中心に、一般的なビジネス場面も混ぜる
- 母語は日本語。説明・指示は日本語、練習する英語は英語で書く

## 1レッスン = 30分 の時間配分(固定)

| # | セクション | 時間 | ねらい |
|---|---|---|---|
| 1 | Warm-up | 3分 | 口を慣らす。前回の復習質問 + 今日のテーマに関する簡単な質問 |
| 2 | Vocabulary & Idioms | 7分 | 単語 8語 + イディオム/コロケーション 4つ。意味・例文・発音注意 |
| 3 | Key Expressions | 7分 | 今日の核となる表現パターン 3〜4つ。置き換え練習(ドリル)と、よくある間違い |
| 4 | Role-play | 10分 | 場面設定 → モデル対話 → 学習者が自分の言葉でやる(バリエーション2つ以上) → 余裕があればチャレンジ |
| 5 | Wrap-up | 3分 | 自己チェック(Can-do)、宿題、次回予告 |

## ファイル形式

- ファイル名: `NN-slug.md`(NN は2桁の番号、slug は英小文字とハイフン)
- 先頭に YAML front matter(`id`, `level`, `title`, `title_en`, `can_do`, `scenario`)を置く
- 見出しは下の雛形と **完全に同じ文言** にする(`## 1. Warm-up (3 min)` など)
- 講師用メモ(Tutor Notes)は `<details>` で折りたたむ
- モデル解答・例は `<details><summary>例 / Sample answer</summary>` で折りたたむ
- 単語表は Markdown のテーブル: `| English | 日本語 | Example |`
- 英語の例文は、そのレベルの学習者が **そのまま口に出して使える** 短さ(原則 12 語以内)にする
- 日本語訳は自然な日本語で。直訳調にしない
- ロールプレイの登場人物名は固定: 学習者は **Ken**(日本のIT企業のバックエンドエンジニア)、相手役は Lesson ごとに設定(例: Sarah = 海外チームのPM, Mike = 同僚エンジニア, Ms. Lee = クライアント)

## 書くときの注意

- 「教科書の英語」より「実際に会議や Slack で使われる英語」を優先する
- 1レッスンに新しい表現を詰め込みすぎない(単語 8 + イディオム 4 + パターン 3〜4 まで)
- レベルが上がるにつれて、例文を少し長く、語彙を少し抽象的にしていく(Level 1: A2, Level 2: A2+〜B1, Level 3: B1, Level 4: B1+〜B2)
- ロールプレイには必ず「予想外の一言」(相手が聞き返す、予定が合わない、など)を1つ入れて、暗記した文だけでは乗り切れないようにする
- 講師用メモには「学習者が詰まったときの日本語ヒント」と「できる人向けの追加課題」を必ず書く
