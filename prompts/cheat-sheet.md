# レッスン中の一言 (Cheat Sheet)

## 講師(Claude)への合図(日本語で OK)

| 言いたいこと | 言い方 | 講師の対応 |
|---|---|---|
| 言い方が分からない | **ヒント** | 日本語で骨格だけ示す(答えは言わない) |
| 聞き取れなかった | **もう一回** | ゆっくり・簡単な言葉で言い直す |
| 意味が分からない | **日本語で** | 直前の内容を日本語で説明 |
| 降参 | **答え** | 模範解答を示して復唱させる |
| 飛ばしたい | **スキップ** / **次** | 次の課題へ |
| 急いでいる | **時間がない** | 残りを圧縮して進める |
| 今日はここまで | **終了** | すぐにフィードバックと記録へ |
| 自分の本当の仕事の話にしたい | **自分の仕事の話で** | レッスンの設定を本人の状況に置き換える |

## 同じことを英語で言うと(慣れてきたら英語で)

| 日本語 | English |
|---|---|
| ヒントください | Can you give me a hint? |
| もう一回言ってください | Could you say that again? / Sorry, one more time? |
| ゆっくり言ってください | Could you speak more slowly, please? |
| 〜はどういう意味ですか? | What does "..." mean? |
| 〜って英語で何て言いますか? | How do you say "..." in English? |
| これで合ってますか? | Is this correct? / Does this sound natural? |
| ちょっと考えさせてください | Let me think for a second. |
| 言い直します | Let me rephrase that. / Let me try again. |
| 分かりました | Got it. / I see. / That makes sense. |
| 飛ばしていいですか? | Can we skip this one? |
| 今日はここまでにしましょう | Let's stop here for today. |

## 詰まったときの時間稼ぎ(ロールプレイで使える)

- Well... / Let me see... / That's a good question.
- How can I put it... (何て言えばいいかな)
- Sorry, I lost my train of thought. (何を言おうとしてたか忘れました)
- What I mean is... (つまり言いたいのは…)
