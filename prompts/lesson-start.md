# レッスン開始プロンプト (Lesson Start)

## Claude Code の場合

スキルがすべて行うので、番号を指定するだけです。

```
/lesson 05
```

自然文でも通じます(CLAUDE.md が `/lesson` を案内します)。

```
レッスン 5 をやりたい
今日は英語のレッスンをお願い(→ 記録から次のレッスンを選びます)
レッスン 5 のロールプレイだけやりたい(→ /lesson 05 roleplay)
```

## claude.ai のチャットの場合

1. サイトのレッスンページで「Claude 用プロンプトをコピー」を押して貼り付ける(講師プロンプト + レッスン本文)。
2. 続けて、必要なら次のように前回の記録を貼る。

```
前回までの記録です。これを踏まえてレッスンを進めてください。

(progress/profile.md の内容)

(直近の progress/sessions/*.md の内容 1〜3 回分)
```

3. 「始めてください」と送る。

## 途中から・一部だけやりたいとき

```
今日は時間が 15 分しかないので、Vocabulary と Role-play だけ短縮版でやってください。
Key Expressions の Drill からやり直したいです。
Role-play の Variation B だけもう一度やらせてください。相手役は Mike で。
```

## 難易度を調整したいとき

```
もう少しゆっくり、短い文で話してください。
もっと速く、ネイティブが実際に使う言い方で話してください。訂正も厳しめで。
ロールプレイで、相手役にもっと意地悪な質問をさせてください。
```
